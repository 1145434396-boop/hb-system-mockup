# 画布规范与导出管线

## 画布

- 画布统一宽 **1640px**（`.stage`），高度按内容实测设定：先拼内容，浏览器量出实际高度，回填到 `.stage` 的 height。禁止留大片空白，也禁止内容溢出。
- 页面内容多时可裁剪：窗口高度截到主要内容展示完为止，底部内容被窗口边缘自然切断是正常的（真实截图也这样）。

## 两种产出（按用途选，开工前必须确认）

### 产品设计类（用户照着搭建）

- **全屏模式**：`<body class="fullbleed">`。真实产品是撑满浏览器窗口的，此模式无衬底、无圆角、无投影，fit.js 把画布缩放到正好等于窗口宽（可放大可缩小），打开就像真的开了伙伴云；导出的 PNG 也是边到边。
- 仅底层窗口，不放 `.callout` 和 `.float`。
- 画面就是一张"产品截图"：界面里的每个元素都必须是伙伴云真实存在的组件和配置能力，用户拿图能直接对照着在平台里搭出来。
- 使用用户确认的项目皮肤或按业务场景推荐的自定义皮肤；产品设计类不默认、也不锁定产品原生蓝。皮肤只改 token，不改变真实组件结构与尺寸。
- 内容用用户业务的真实字段名、真实数据样例，不用占位文案。

### 营销类（报告配图 / 宣传讲解）

- **画布模式**（默认，不加 fullbleed）：窗口是带圆角投影的卡片，浮在皮肤衬底（`--backdrop`）上，四周留白给浮层和标注气泡用；这是"一张图"，不是"一个系统"。
- **底层＋浮层**：`.stage.has-float` 时窗口收窄到 1440，浮层向右探出补满 1640；无浮层则窗口撑满。
- 浮层（`.float`）位置任意，但只能**补充底层尚未出现的内容**，可用两种形态：
  1. **新组件示意**：展示底层没有的相关真实组件，如快捷表单、任务清单或第二业务视角。
  2. **点击结果态**：展示底层某个操作触发后、当前画面尚未出现的真实结果态，如弹窗、下拉或提示。
- **禁止重复放大**：不得把底层已有卡片、字段、统计、表格或相同信息复制到浮层中；需要强调底层已有内容时，仅调整底层自身的对比关系，不再画第二份。
- `.callout` 标注气泡只在用户明确要求业务价值标注时添加，不作为营销类默认元素；不得压住组件或替代缺失内容。
- 浮层内容必须是伙伴云已有组件，强调≠虚构；不得为给浮层腾位置而裁短底层窗口，底层计划展示的内容必须完整。

## 组装方式

单文件 HTML：`<style>` 里依次内联 base.css → 皮肤 css → 本图特有的少量补充样式，`<body>` 里放 `.stage`，文件末尾内联 `<script>`（assets/fit.js，画布自适应：窗口窄于画布时整体等比缩小，打开即看全图）。不外链文件，保证单文件可渲染可交付。css 和 fit.js 用 cat 拼接，不手抄进上下文。

## 验证（每张图必做）

1. 浏览器打开渲染，截图核对：高度贴合、无溢出、无空白、字号层级正常。
2. 对照 `references/principles/` 自检：对齐（列数一致、不定高独占行）、状态色红绿灯、按钮分级（主/次/警示/置灰）、图表选型正确。
3. 界面里的组件名称、交互形态与结构文件（assets/c1～c3）名录一致，无自造组件。

## 导出

### 2x PNG（默认交付物）

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --screenshot=out.png \
  --window-size=<宽>,<高> --force-device-scale-factor=2 \
  --hide-scrollbars "file:///路径/图.html"
```

- 产品设计类（全屏模式）：window-size = `1640,<stage高>`，PNG 边到边无边框。
- 营销类（画布模式）：window-size = `1704,<stage高+96>`（1640＋body 左右 padding 32×2），PNG 带皮肤衬底。
- PNG 一律不透明底：手机端 PDF 阅读器会把透明像素渲成灰块。

### SVG 嵌报告（hb-digital-proposal 用）

取 `<style>`＋`<div class="stage">…` 包进 `<svg><foreignObject><div xmlns="http://www.w3.org/1999/xhtml">`，尺寸取 `.stage` 实际宽高。三个必修点，漏一个整图变纯文本或不渲染：

1. 所有内嵌图标 `<svg` 必须补 `xmlns="http://www.w3.org/2000/svg"`；开头写法有 `<svg width` / `<svg class` / `<svg viewBox` 多种，按 `<svg ` 统一处理，别按前缀枚举。
2. `<br>` 转 `<br/>`（foreignObject 里是 XML）。导出后先 `xml.etree` 校验再嵌。
3. foreignObject 前垫一个全画布 `<rect>`（填报告纸色）：留透明像素，手机端 PDF 阅读器会渲成灰块。
