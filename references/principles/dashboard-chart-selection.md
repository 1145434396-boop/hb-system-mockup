# 图表选型：分析方法到组件的映射

选图先问分析目的（看趋势还是看对比），再选图表，图表不能乱用。按数据故事三问组织：

## 发生了什么

### 度量分析（快速看到关键数字）

| 组件 | 用途 |
|---|---|
| 统计指标 | 卡片式展示一个关键指标值，右侧可带近期趋势变化（一个区域两种维度） |
| 进度条 | 当前 vs 目标的对比，进度一眼可见 |
| 多项统计 | 多个维度的数据统计在一张小卡片里 |

### 趋势分析（随时间的变化规律）

| 组件 | 判据 |
|---|---|
| 折线图 | 关注**独立趋势和变化规律**；各系列间没有总量/包含关系（零食销售额 vs 饮料销售额） |
| 面积图 | 关注**此消彼长、占比变化**；各系列构成一个总量（堂食 vs 外卖、24 小时时间分配） |
| 双轴图 | 左右两个 Y 轴两种度量，可同图混用折线＋柱（销售额＋转化率） |

折线图能做的面积图也能做，但选"最合适"的：没有总量概念就用折线。

## 为什么会这样

### 对比分析（找差异）

| 组件 | 判据 |
|---|---|
| 柱图 | 类别 ≤ 12 个（对应 12 个月的常见场景） |
| 条形图 | 标签名称长、分类多（> 12 项）、或有负值 |

### 构成分析（看组成结构）

| 组件 | 用途 |
|---|---|
| 饼图 / 环图 | 占比；配置里可自由切换饼/环 |
| 分类汇总 | 基于选项字段做各状态占比排名 |
| 透视表 | 类 Excel 透视，按多维度看构成 |

## 我该怎么办（专项分析）

| 分析 | 组件 | 要点 |
|---|---|---|
| 漏斗分析 | 漏斗图 | 各阶段转化，识别瓶颈环节；**必须勾选"累加下一组数据"**，否则漏斗奇形怪状 |
| 关系分析 | 散点图 | 两个变量的相关性（X/Y 轴） |
| | 气泡图 | 三个变量：散点基础上用气泡大小表达第三维 |
| 位置分析 | 地图 | 省或省市两级；颜色深浅表数据多少 |
| 明细分析 | 网格视图 | 筛选、搜索、排序看原始数据。看板数据可信的根基：每个数都能追溯到原始数据，从宏观到微观闭环 |

## 让看板动起来（探索式五组件）

| 组件 | 能力 |
|---|---|
| 筛选组件 | 对页面所有组件生效；筛选项按字段类型动态出现 |
| 联动筛选 | 一处操作全局响应（点饼图一块，下方全变）；图表组件和透视表都支持，在图表配置下方设置 |
| 钻取 | 从汇总层层下到明细。**自由钻取**：无路径限制，适合探索性分析，图表类型不变；**路径钻取**：预设层级，每层可切换图表类型和数据源（部门柱图 → 编制饼图），适合总分式分析。配好后图表右上角有开关图标，开启后点图任意区域出钻取菜单 |
| 同比环比 | 时间维度对比（本月 vs 上月、今年 vs 去年）；在量化字段菜单里配置，显示值可选数值或百分比，悬停查看 |
| 分项对比 | Y 轴量化配置里选一个维度（如性别），柱图自动按维度分色 |
