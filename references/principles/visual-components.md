# 组件规范：表单、按钮、页面层级、打印模板

## 表单设计（微观秩序）

- **纵向对齐**：表单最多四列；相邻区域列数保持一致，不要 1、2、3、4 列随意混排。
- **横向对齐**：不定高字段独占一行，不与其他字段同行（否则像参差的牙齿）。典型不定高字段：多行文本、设为多选的选项/关联数据。
- **亲密性**：不做一泻千里的长表单；用表单说明拆业务板块，用子表、标签页等组件把相关字段收进一个层级。
- **填写动线**：需要手动填写的字段靠左，能用默认值处理的放右边。用户从上到下顺着左边一条直线填完，默认值扫一眼不用动，鼠标不乱晃。
- 检验方法：把自己当用户，搭完自己去填一次。

## 按钮分级（对比原则的落地）

| 级别 | 样式 | 用途 |
|---|---|---|
| 主要按钮 | 填充 | 核心业务推进；一个操作区域不要放多个主按钮，主按钮多了就不主要了 |
| 次要按钮 | 描边（边有色、中间镂空） | 辅助操作，视觉权重低，配合主按钮 |
| 警示按钮 | 警示色 | 破坏性操作（删除、作废、退回），用颜色防误操作 |

- 再加一层"能用/不能用"：用置灰表达当前不可用。
- 文字之外可加图标，降低认知负担。
- 不同角色用的按钮做权限组区分。

## 页面层级

- 页面结构四层：页面 → 分页 → 容器 → 组件。复杂页面（大屏、官网）先想清层级，避免多层背景叠加。
- 样式复制：组件样式面板可一键复制/粘贴样式，跨组件统一样式；觉得哪个模板好看可以直接复制它的样式，践行重复原则、显著提升搭建效率。

## 打印模板

- 有命名、字体、页面布局三方面规范；规范定下来后大量模板靠复用。支持上传字体做个性化。
