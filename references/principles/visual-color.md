# 配色：三色原则、状态色、品牌植入

## 三色原则（对应"对比"）

颜色越少，重点越突出。比例：

- **60% 主色**：中性色（白、浅灰），业务系统大量底色必须是安静的
- **30% 辅助色**：可用客户品牌色，做出专属感
- **10% 提亮色**：高饱和颜色做点缀

## 状态色标准（对应"重复"）

记忆法：红绿灯，全球统一无歧义。用于选项字段、快捷按钮等所有状态表达：

| 状态 | 颜色 |
|---|---|
| 成功 / 完成 / 审批通过 | 绿 |
| 进行中 | 蓝 |
| 警告 / 待办 | 黄 |
| 失败 / 危险 | 红 |
| 未开始 / 其他 | 浅灰 |

## 用色纪律

- **优先纯色，慎用渐变色**。渐变想做清爽难度极大，能驾驭渐变是配色大师的门槛。
- 取色不拍脑袋：参考 Ant Design 的 B 端色板（12 系基础色，同系颜色相互搭配），或用在线配色生成器按三原色方案生成；品牌色用取色工具从客户 logo/图片吸取。
- 色值用 Hex 代码（# 开头六位）传递，平台所有颜色选项点开彩虹面板都支持自定义 Hex 输入。
- 不确定就用系统默认配色，起码不会丑。

## 品牌基因植入

- 企业设置里配好图片、名称、空间地址；壁纸选用与客户品牌相关的配色。
- 工作区左下角"管理"里配图标、名称、外观颜色。外观选一个主色后，整个工作区是一整套配色规范联动切换（浅蓝、灰蓝等都随主色变），不是单换一个色。
